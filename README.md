# iPhone 批量管理工具（iPhoneBatchTool）

一站式 iPhone 批量管理工具，适用于工作室、自媒体的多设备批量管理场景。

## 功能特性

- **批量备份**：多台 iPhone 同时整机备份，自动记录小红书等应用账号信息
- **批量恢复**：一键批量恢复备份，支持跨机恢复、资源注入
- **自动激活**：检测未激活设备自动执行激活（无需手动操作）
- **跳过设置向导**：自动完成语言/地区设置与云配置，无需重启
- **批量装应用**：勾选应用自动批量安装
- **在线查询**：临时备份快速查询小红书在线数据
- **加密备份**：支持加密备份，保护数据安全
- **自动更新**：内置更新通道，启动自动检查新版本

## 下载安装

前往 [Releases](https://github.com/dvebenbao/iphone-batch-tool/releases) 页面下载最新版安装包，双击运行即可完成安装。

## 使用环境

- Windows 10 / 11
- iPhone 设备（USB 连接，需信任此电脑）
- 首次使用需安装 iTunes（含驱动）
